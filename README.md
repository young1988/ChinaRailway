# 铁路足迹 · ChinaRailway

把坐过的火车画在地图上。粘贴 12306 短信，或直接填车站名，系统会沿 **真实轨道线位**
把这段行程点亮，并统计里程、省份覆盖，再配上「迷雾地图 / 多底图 / 铁路专注」等视角，
满足铁路爱好者与路线收集解锁党的乐趣。

> Web 优先实现，主体是纯静态页，**保留迁移到微信小程序的能力**
> （数据层已抽象为 `Store`，可无缝替换为云开发）。
> 唯一的后端 `server.py` 是**可选**的：不起也能用，只是车次查不到实时经停站。

## 功能特性

- **三种录入方式**
  - 按车次录入：粘贴车次号 → 列出该车次**全部经停站** → 点选乘车站 / 下车站 → 自动记录
    （车次数据来自 12306 官方接口，可选实时查询）
  - 粘贴 12306 购票短信（`A 至 B` / `G1 次` 自动解析出发到达与日期）
  - 手动录入任意车站（全国 10301 个站名，自动吸附到最近轨道）
- **真实线位还原**：用 OSM 全路网（高铁 + 普速）构建统一图，端点吸附 + 堆优化 Dijkstra 逐段最短路
- **高铁 / 普速偏好**：自动 / 高铁优先 / 普速优先
- **迷雾地图**：未走线路压暗，已点亮行程高亮，越走越清晰
- **多底图**：正常 / 纯黑（官方夜间样式）/ 卫星图，自动切换配色
- **铁路专注**：弱化公路文字注记与 POI，突出铁路
- **线路图鉴**：按高铁 / 普速 / 窄轨分类，字母分组 + 拼音首字母 + 别名搜索，多选高亮与里程统计
- **跨海轮渡**：琼州海峡火车轮渡（OSM 无此数据，手工建模），打通海口 ↔ 湛江
- **本地持久化**：localStorage 存档 + 多档案 + 导出 / 导入 JSON 备份
- **统计口径**：里程、覆盖省份、线路类型占比

## 运行

地图底图使用腾讯地图 GL JS，需要一个地图 Key（在面板「地图 Key 设置」里填，或 URL 带 `?key=`）。

**静态运行**（拿不到实时经停站，用本地快照）：把 `railway-demo/` 作为静态站点部署即可，
任意静态托管均可；也可以直接双击 `index.html` 用 `file://` 打开。

**带实时车次查询**（推荐）：

```bash
python3 railway-demo/server.py        # 默认 127.0.0.1:8787
# 然后打开 http://127.0.0.1:8787/
```

服务端会把 12306 的两步接口串起来（`search` 拿车次号与起终站 → `queryTrainInfo` 拿完整经停站）。
不起服务端时，页面仍会通过浏览器直连 `search` 接口告诉你「车次在不在、起终站是哪」。
代理部署在别处时，用 `localStorage['RW_TRAINAPI_BASE']` 或 URL 参数 `?api=` 指过来。
