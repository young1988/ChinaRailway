# 铁路足迹 · ChinaRailway

把坐过的火车画在地图上。粘贴 12306 短信，或直接填车站名，系统会沿 **真实轨道线位**
把这段行程点亮，并统计里程、省份覆盖，再配上「迷雾地图 / 多底图 / 铁路专注」等视角，
满足铁路爱好者与路线收集解锁党的乐趣。

> Web 优先实现，纯静态，**保留迁移到微信小程序的能力**（数据层已抽象为 `Store`，可无缝替换为云开发）。

## 功能特性

- **三种录入方式**
  - 粘贴 12306 购票短信（`A 至 B` / `G1 次` 自动解析出发到达与日期）
  - 手动录入任意车站（全国 10301 个车站库，自动吸附到最近轨道）
  - 预置车次（演示用 12 个车次）
- **真实线位还原**：用 OSM 全路网（高铁 + 普速）构建统一图，端点吸附 + 堆优化 Dijkstra 逐段最短路
- **高铁 / 普速偏好**：自动 / 高铁优先 / 普速优先
- **迷雾地图**：未走线路压暗，已点亮行程高亮，越走越清晰
- **多底图**：正常 / 纯黑（官方夜间样式）/ 卫星图，自动切换配色
- **铁路专注**：弱化公路文字注记与 POI，突出铁路
- **本地持久化**：localStorage 存档 + 多档案 + 导出 / 导入 JSON 备份
- **统计口径**：里程、覆盖省份、线路类型占比

## 目录结构

```
ChinaRailway/
├── railway-demo/           应用（纯静态，直接部署）
│   ├── index.html          页面 + 全部逻辑（Core / MapAdapter / Store / App 四层）
│   ├── highspeed_lines.js  高铁/城际路网（清洗后，约 484KB）
│   ├── conventional_lines.js  普速路网（约 488KB）
│   ├── stations_all.js     全国车站库（10301 站，约 276KB）
│   ├── lines_real.js       10 条演示干线几何
│   ├── stations_real.js    74 个演示站
│   └── tools/              抓取与清洗脚本（Python，需联网拉 OSM）
├── 铁路足迹-使用文档.md     面向用户的使用说明
└── 铁路足迹-技术方案_v1.md  架构与实现思路
```

> `railway-demo/tools/raw*/` 为抓取原始数据（约 356MB），**已通过 `.gitignore` 排除**，不会进入仓库。

## 运行

地图底图使用腾讯地图 GL JS，需要一个地图 Key（在面板「地图 Key 设置」里填，或 URL 带 `?key=`）。
拿到 Key 后，把 `railway-demo/` 作为静态站点部署即可（任意静态托管均可）。
